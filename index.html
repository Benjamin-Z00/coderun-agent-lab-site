每一阶段都对应一个可运行项目。学员不是听完一章，而是完成一个被测试和验收的交付物。

Agent 工程底座

02

05

FDE 交付包

PoC 需求、成功指标、Demo 脚本、上线 Checklist、Runbook、复盘报告。

项目实战

第一版只围绕 5 个项目，让自学用户有清晰终点。

Project 01

LLM Gateway

统一模型调用、结构化输出、Streaming、Prompt 模板和成本记录。

  • 可运行 API 服务
  • 单元测试与错误重试
  • 模型调用成本报表
Project 02

Tool Runtime

让模型安全调用外部工具，并记录权限、参数、结果和审计链路。

  • 工具注册与发现
  • 权限分级与人工确认
  • MCP 接入练习
Project 03

CodeRun AI 助教

基于模拟课程资料、FAQ、题目说明和报错样例，交付一个 RAG 答疑 Agent。

  • 引用来源回答
  • 问题分类和摘要
  • 知识权限过滤
Project 04

Codebase Agent

搜索代码、读取文件、修改代码、运行测试，并把每一步记录为 Trace。

  • Agent Loop 实现
  • 安全执行边界
  • 失败任务 Replay
Final Pack

FDE PoC 交付包

把前面项目包装为一个企业 AI 助教 PoC，输出方案、Demo、验收和上线资料。

  • PoC 需求文档
  • 验收标准与 ROI 假设
  • 作品集讲解稿
