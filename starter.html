Week 0 参考运行结果

自学时先对照这些结果，判断自己是否真的跑通。

这里提供的是验收样例，不是完整讲解。你的结果不需要每个数字完全一致，但状态、字段结构、测试通过数量和 README 记录应该能对上。

健康检查

启动服务后访问 /health，应该看到服务处于可用状态。

{
  "status": "ok"
}

接口文档

访问 /docs，应该能看到健康检查、聊天、结构化输出、流式输出和用量统计接口。

GET  /health
POST /v1/chat
POST /v1/structured
POST /v1/chat/stream
GET  /v1/usage

测试结果

执行 pytest 后，核心测试应全部通过；不同机器上的耗时会不一样。

常见不通过

如果遇到依赖、虚拟环境或端口占用问题，先按报错信息定位，不要直接改业务代码。

Port already in use
pytest command not found
