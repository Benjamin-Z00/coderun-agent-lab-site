Quick Start 
git clone https://github.com/Benjamin-Z00/llm-gateway-starter.git
cd llm-gateway-starter
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload

你会拿到什么

一个能运行、能测试、能继续扩展的 Agent 工程底座。

工程代码

FastAPI 服务、统一模型调用接口、Fake Provider、结构化输出、流式响应和用量统计。

自学任务

7 个任务文档，按“读说明、改代码、跑测试、记录作品集”的方式推进。

作品集模板

README 模板会引导你记录架构、关键接口、测试结果和后续可扩展点。

第一天任务

不要先补理论，先让项目在本地跑起来。

01

完成本地启动

启动服务后访问 /health，确认返回正常状态。

02

跑通测试

执行 pytest，确认接口、结构化输出、流式响应和用量统计通过。

03

完成任务 01

阅读 tasks/01-run-locally.md，把运行截图和问题记录进作品集模板。

04

写 100 字复盘

说明这个 Gateway 为什么是 Agent 项目的底座，以及它后续还能接哪些能力。
